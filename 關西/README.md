# 關西行程表（草稿）

- 成員：兩大人 + 一位三歲小孩
- 季節：12 月（避開年末年始 12/24–1/3）
- 模式：自駕為主（車＝移動基地，車上補眠，整天出遊）；市區日車留住處改搭電車＋計程車
- 住宿：Airbnb 老屋改造一棟租
- 天數：先抓 6 天 5 夜骨架，實際天數再增減

---

## 冬季 × 三歲 × 自駕｜京都 6 天骨架

排法邏輯：室內景點擋冷、車日負責長距離補眠、市區日車留住處改搭電車＋計程車。每天下午留一段放電，不然晚上收不了。

### Day 1｜抵達・暖身（半天）
- 關西機場取車 → 進京都 / 或直接進鄉間住處
- 超市採買（冬天鄉下超市 19:00 關，先買好晚餐＋隔天早餐）
- 抵達先開暖氣再出門——一棟租沒人先暖房，空調要 1–2 小時才起來
- 放電：住處附近走走就好，別排點

### Day 2｜京都鐵道博物館 + 水族館（市區日，車留）
- 梅小路這一區是冬天帶三歲的天花板：鐵道博物館（可以上車、有蒸汽火車）＋京都水族館，兩館走路 5 分鐘，全室內
- 中間夾梅小路公園放電（有大草坪、小電車）
- 這天完全不用開車，住市區的話走路 + 一兩趟計程車搞定

### Day 3｜奈良公園餵鹿（車日）
- 開車去奈良，停好車就是平地，小孩可以放開跑、追鹿、餵仙貝——三歲最愛的一天
- 東大寺大佛（室內、震撼）
- 車程去回各約 1 小時，剛好一個午睡
- ⚠️ 鹿會頂小孩討餅，仙貝拿在大人手上分

### Day 4｜出城大自遊（車日，你們的主場）
二選一，看想要什麼：
- 琵琶湖博物館（草津）——日本最大湖泊博物館，水族＋體驗區，室內，腹地大，冬天首選
- 美山茅葺之里——若 12 月下旬有雪，雪景茅葺極美；但山路要雪胎，且冷，看天氣賭
- 這種日子最適合你們：車上睡、下車就到、目的地本身好停車

### Day 5｜東山散步（市區日，車留）
- 這片車幫不上忙，直接放住處：清水寺 → 産寧坂 → 二寧坂 → 八坂 → 祇園，是「停一次走兩三小時」的散步型區域
- 用計程車直送清水寺下面（唯一能把小孩送到坡底的方式），之後一路往下走回來
- 早上先衝伏見稲荷（千本鳥居隧道，小孩會覺得像闖關，起點段平緩，走到累就折返）
- 髖凳（hip seat）必帶，給「突然睡著」跟最後一公里

### Day 6｜收尾・離開
- 看時間：金閣寺（快、好拍）或錦市場，或直接還車去機場
- 買伴手禮

---

## 幾個貫穿全程的提醒

- 一天只排兩個主點，京都點跟點距離都不短，貪多小孩會崩
- 早上 9 點前到熱門點，冬天人少、停車也好停（你們早出門是巨大優勢）
- 市區停車用 akippa / Times B 事先預約，免繞路免「満車」
- 冬天室內備案要多備一個（鐵博、水族館、琵琶湖博物館都是雨天／太冷的救援）
