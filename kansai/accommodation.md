|  |  |

### 這間的規範（房東確認）

- **入住 15:00–20:00**，20:00 後無法入住。
- **22:00 宵禁上鎖** — 22:00 後會上鎖無法進入。
- **入住當天要先告知房東抵達時間**。
- **家庭浴缸** — 浴室為家庭式浴缸，共用需協調使用時段。
- **無廚房** — 早晚餐外食或外帶（東山周邊選擇多）。
- **提早寄放行李**：房東已確認可提早寄放，Day 1 中午抵達可先寄放行李再出門。

## 共通規範（兩間都要遵守）

- **入住 15:00 / 退房 11:00** — 早到先寄放行李，別逕自進房。
- **安靜** — 兩間都是老屋／與房東同棟，晚上輕聲、避免吵到鄰居與房東。
- **垃圾分類** — 依房東指示分類（日本很嚴格），離開前整理好。
- **室內脫鞋** — 日式住宅慣例。
- **不多住人** — 依人數上限，不臨時加人。
- **離開前** — 關窗、關電器、垃圾處理、鑰匙依房東指示歸還。
