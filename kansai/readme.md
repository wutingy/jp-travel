# Day 1 (11/21)：抵達關西 → 京都

- 去程航班：虎航 **IT210** 台北桃園 07:00 → 關西 KIX 10:25（全體同班）
- 關西機場 → **JR 特急 Haruka（はるか）** 直達京都（約 75 分，直達；認明 **JR** 指標）
  - 4 大人＋2 小孩，買 **指定席（對號）**（關西機場 JR 綠色窗口／售票機）
- 京都站 → 住宿（東山・祇園）：
  - 🚌 **市巴士 206（一車直達）**：京都站前搭 → 「祇園」或「清水道」下車
  - 🚆 或 **JR 奈良線**到「東福寺」→ 出站換**京阪本線**（京阪電車，不同公司、需分開購票）到「祇園四條」（約 10 分）
- 住宿：[東山飯店](https://www.google.com/maps?cid=11028362320118606978&hl=ja&gl=JP) check-in 15:00；抵達較早先**寄放行李**再出門

### 下午散步路線

1. 住宿放行李
2. 往[**花見小路**](https://maps.app.goo.gl/PM2FE1SaKsSTAP6M8)走逛逛
3. **五條大橋／四條大橋**賞鴨川
4. 河畔咖啡廳午茶、歇腳
5. 15:00 後回飯店辦理入住

# Day 3 (11/23)：京都水族館・桂離宮／購物

> 💡 備註：感覺太累可不去京都水族館。

## 上午：京都水族館・桂離宮

**思因單獨去桂離宮，其他人一起到京都水族館（梅小路公園）**——兩邊各自從住宿出發，不用先一起到水族館。

### 🚌 其他人：住宿 → 京都水族館

- [「東山安井」](https://maps.app.goo.gl/sCAhtxhKZ5nuwmgf8)站搭 **207 號公車** → [「七條大宮・京都水族館前」](https://maps.app.goo.gl/QZZ9RSAkc3iastQB9)下車（約 20–25 分），步行 3–5 分。
- 🎟️ 門票當天**蓋手章可重複進出**；館內約 1.5–2 小時，有空可到梅小路公園大草坪玩，或順遊隔壁**京都鐵道博物館**。

### 🚉 思因：住宿 → 桂離宮

- 從住宿前往桂離宮（西京區）。
- ⏱️ 導覽約 60 分；⚠️ 桂離宮導覽制、**需事先預約**（宮內庁官網）。

## 傍晚：購物

- 移動：**地鐵**／河原町一帶步行
- 🛍️ **無印良品**：[京都BAL](https://maps.app.goo.gl/Khths4gn2ktU2gtS8) 5F（河原町通三条下ル；11:00–20:00，另有 Café&Meal MUJI 4F）
- 🏃 **運動用品**：BAL 沒有，走到附近寺町京極／[**新京極商店街**](https://maps.app.goo.gl/Wu7LoGGW4wFE3FhGA)一帶找

# Day 4 (11/24)：宇治

### 宇治順遊（京阪電車）

1. [**祇園四條站**](https://maps.app.goo.gl/6Sm5m9dVo6dczrGUA)搭**京阪本線**→「**中書島**」轉**京阪宇治線**→ [**京阪宇治站**](https://maps.app.goo.gl/sJYCUWFTJMzwy6Rq7)（皆京阪電車、同站轉乘一票到底，車程約 30 分）
2. 參拜**宇治神社・宇治上神社**（車站同側）
3. 穿過**宇治公園（中之島）**、跨宇治川到對岸 → 漫步[**平等院表參道**](https://maps.app.goo.gl/ZKLgo6MJWPvTTGYo6)、參觀[**平等院・鳳凰堂**](https://maps.app.goo.gl/D6M9n8N5FKTq67vy5)
4. 午餐、甜點（表參道或川邊）
5. 河岸茶屋下午茶
6. 搭電車返回京都市區（表參道店家約 17:00 打烊）

# Day 9 (11/29)：關西機場 → 高雄／台北

> ⚠️ 兩組回程降落城市不同：**A 組（吳亭儀・陳思因＋2 小孩）回高雄**、**B 組（吳燦東・劉秀蓮）回台北**。訂位細節見 `flights-booking.local.md`（本機檔，未進版控）。

| 路線 | 交通方式 | 時間 |
|------|----------|------|
| 近江舞子 → 關西機場 | 開車・還車 | 約 1.5-2h |

### 航班（皆 11:30 起飛）

| 組別 | 回程航線 | 航班・時間 |
|------|----------|-----------|
| A 組 | 大阪 KIX → 高雄 KHH | 虎航 IT285，11:30 → 14:00（直飛） |
| B 組 | 大阪 KIX → 台北 TPE | 虎航 IT211，11:30 → 13:50 |

### 移動安排

- 🔴 兩組都 11:30 起飛 → **全體 07:00 一起出發**（開車約 2h ＋ 還車接駁 30 分 ＋ 國際線報到需起飛前 2h）
- 💡 前一晚打包好、早睡；房東已確認可**提早自行退房**
- 近江舞子退房 → 開往關西機場（約 2h）→ 還車
- ⚠️ 還車前記得**加滿油**
- 到機場報到、託運、退稅
