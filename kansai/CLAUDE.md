# 關西旅遊資料夾：寫作風格

這個資料夾是一家人 2026/11/21–11/29 關西旅遊的行程、待辦和預訂紀錄。讀的人是家人，不是工程師。新增或修改內容時照下面的寫法。

## 不用 emoji

- 新寫的內容一律不用 emoji，標題、清單、表格、Modal 都一樣。
- 狀態用文字寫：「已訂」「已付款」「已確認」「待確認」「還沒訂」。
- 重點用**粗體**或放在前面，不要用符號圖示來強調。
- 舊內容裡已經有的 emoji，除非使用者要求，不要順手全部清掉；改到那一行時再一起換成文字。

## 語言與語氣

- 繁體中文，用台灣的講法。
- 白話、短句，先講結論再講原因。
- 日本的地名、店名、站名保留日文原名，例如「東福寺」「近江舞子」「りんくうタウン」；需要時在後面加中文說明。
- 稱呼家人用 repo 裡的寫法：吳亭儀、陳思因、吳宇在、吳宇若、吳燦東、劉秀蓮。回程分組：A 組（吳亭儀・陳思因＋2 小孩）回高雄，B 組（吳燦東・劉秀蓮）回台北。

## 只寫確定的事

- 使用者要加的項目照原樣加，不要自己補用途、理由或備註。
- 時間、金額、班次以使用者給的資料或訂單為準。資料之間對不上時，先問使用者，不要自己挑一個。
- 查不到或不確定的數字寫「需確認」，不要猜。

## 格式

| 項目 | 寫法 | 例子 |
|---|---|---|
| 日期 | 月/日加全形括號星期 | 11/21（六） |
| 行程天數 | Day N（月/日） | Day 7（11/27） |
| 時間 | 24 小時制，兩位數 | 07:00、16:05 |
| 時間區間、路線 | 用 → | 高雄 16:05 → 臺東 18:32 |
| 日幣 | ¥ 加千分位 | ¥13,600 |
| 台幣 | NT$ 加千分位 | NT$4,200 |
| 並列的人或地點 | 用「・」 | 吳燦東・劉秀蓮 |
| 括號、引號 | 全形 | （）「」 |

- 班次、時間、金額、代號這類要一眼找到的資訊用**粗體**。
- 標點用全形；數字、英文和代號用半形。

## 各檔案的慣例

- **todo.md**：上半部「還沒做」依時間先後排，每組標上日期；下半部「Archived」放已完成的項目，保留原本內容當參考。做完一項就移到 Archived。
- **readme.html**：餐廳、景點的候選用 `pick` 標籤標「當天主選」或「備」。補充細節（搭乘教學、訂位資訊、時刻表）做成 Modal：在內文加 `<span class="ilink" role="button" tabindex="0" data-modal="xxx">`，在頁面下方加對應的 `<div class="modal" id="xxx" hidden>`，id 用英文小寫加連字號。
- **packing-list.md**：清單項目用核取方塊 `- [ ]`。

## 私密資訊

這個 repo 是 public，會發布成網頁。

- 護照號碼、生日、訂位代號（PNR）、訂票代碼、受付番号、電子票連結這類資料，放在 `*.local.md` 私密檔，不寫進一般檔案。
- 一般檔案裡要提到時，寫「在私密檔 `xxx.local.md`」。
- `*.local.*` 已在 `.gitignore`，不要改掉這條規則。

## Commit

- 不要自動 commit。改完留在工作區，使用者說「commit」才提交，說「push」才推上去。
