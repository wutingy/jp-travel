市巴士 206　京都站 → 東山

從 JR 下車到搭上 206 號巴士，流程非常直覺，只要記住出站出口與月台編號即可。

步驟一：出站（認明「中央口」）

  • 搭 JR 特急 Haruka 抵京都站後，順指標往 「中央口」（Central Exit） 走。
  • 出中央口剪票口後，正前方就是高高的 京都塔。

步驟二：走出車站，前往站前巴士總站

  • 看到京都塔後往正前方門出站，門外就是 「京都站前巴士總站（京都駅前バスターミナル）」。
  • 地面與標示牌都有清楚的英文分區（A、B、C、D 候車區）。

步驟三：尋找「D2」乘車處

  • 往右前方找 「D 區」的「D2」月台。
  • D2 主要前往：三十三間堂・清水寺・祇園・北大路バスターミナル。
  • 認明排隊線上的 市巴士 206 號（經東山通／東山経由）。
💡 重要注意事項
  • 千萬別搭錯方向：206 是環狀線。往「清水道」「祇園」一定要在 D2（經三十三間堂、東山通）；跑到別的月台搭到往「千本通／四条大宮」的 206，會繞京都西側一大圈。
  • 乘車與付款：後門上車、前門下車付款；可用 ICOCA／Suica 感應，或現金（單程均一 230 日圓）。
  • 備選（D2 人多時）：同在 D 區可搭 市巴士 86、106 號 或觀光特急 EX100，同樣到「五條坂」「清水道」。

計程車（Taxi）　京都站 → 東山飯店

針對 4 位大人 ＋ 2 位幼童與大行李，搭計程車是最輕鬆、省力的直達方式。

步驟一：出站（認明「烏丸口／中央口」）

  • 搭 JR 特急 Haruka 抵達京都站後，往 「中央口（烏丸口）」 方向出站。
  • 出站後向右走，即可看到標示清晰的 「計程車乘車處（タクシー乗り場）」。

步驟二：搭乘安排與溝通

  • 分乘 2 台車：建議 2 大人 ＋ 1 小孩 ＋ 2 個大行李箱 / 台。
  • 給司機看地址／名稱：
    把地址展示給司機：京都市東山区祇園町南側526
    或說明：「東大路通の八坂神社南側（安井交差点近く）へお願いします」。

車程與費用預估

  • 車程：約 3.5 公里，10–15 分鐘直達飯店門口。
  • 預估費用：單程約 1,300～1,600 日圓 / 台（2 台合計約 2,600～3,200 日圓，約 NT$600 前後）。
💡 優勢與注意事項
  • 完全不需拉行李擠公車：免去賞楓季公車人擠人與塞車的不便，直接將行李箱送達飯店。
  • 行李空間：一般計程車（含 JPN TAXI）後備箱可放 2 個 28 吋大行李箱；若行李較多可請站務人員指引排大型計程車。

Visit Japan Web 日本入境與通關流程

完成線上填寫後，請依以下步驟於關西機場（KIX）辦理入境與通關：

Step 0：出發前準備（截圖備用）

  • 填完 Visit Japan Web 後，點選「入境審查及海關申報」生成合一的 QR Code。
  • 💡 務必將 QR Code 手機截圖存入相簿（或列印備用），避免機場 Wi-Fi 訊號不穩。
  • 2 歲小孩綁在大人同行家人名下，通關時隨同大人一起走即可。

Step 1：抵達與隨人群前進

  • 下飛機後順著「到着 / Immigration / 入境」指標向前走。

Step 2：入境審查（過海關貼貼紙）

  • 排「外國人（Foreign Passport）」通道。
  • 出示：護照 ＋ Visit Japan Web QR Code（手機截圖即可）。
  • 配合工作人員指引按壓雙手食指指紋、臉部拍照，審查官會在護照上貼「短期滯在」上陸許可貼紙。

Step 3：領取行李

  • 順著指標到行李大廳，看螢幕顯示 IT210 的轉盤領取托運行李。

Step 4：海關申報（走電子申告閘門）

  • 領完行李後往出口走，看到「電子申告閘門（Customs Gate）」。
  • 全家人（含大人小孩）可一起走電子申告區，再次掃描同一組 Visit Japan Web QR Code ＋ 護照／人臉辨識，閘門自動開啟即可出關！
💡 入境後搭乘 Haruka
出管制區後搭電梯／手扶梯上 2 樓，通過連絡橋前往 JR 關西機場站，於綠色窗口或自動售票機領取／購買 Haruka 指定席車票 直達京都。

還車前加油　關西機場（りんくうタウン）

ORIX 是「還車要滿油」。機場島上沒有加油站，過了關空聯絡橋就加不到，所以務必在過橋前的りんくうタウン加滿。

推薦加油站

  • ENEOS りんくうタウンSS（首選）
  • 地址：大阪府泉佐野市りんくう往来南 5-50
  • 24 小時營業 — 清早也開著
  • 位置：りんくうタウン、過聯絡橋前最後一區，加完直接上橋進機場還車，幾乎不繞路
  • カーナビ 直接搜「ENEOS りんくうタウン」或「りんくう往来南」；阪和道走りんくう出口即到

還車流程

  • 加滿油 → 留好加油收據（レシート）
  • 過聯絡橋 → 還車店：ORIX 関西空港店（エアロプラザビル 1F，TEL 072-456-8780）
  • 還車時出示收據；現場結清費用（現地決済 ¥86,268，刷下訂的信用卡）
⚠️ 沒加滿的後果
  • 沒加滿油，ORIX 會用自家較貴油價幫你補，可能再加手續費。
  • 還車時間預約 09:00：07:00 從近江舞子出發、開約 2h，記得把加油時間也算進去。班機 11:30，時間仍充裕。
